ReplayHouse — a ClickHouse replay buffer in your browser tab

real MergeTree tables, real weighted sampling — the OLAP engine is WebAssembly running on this page. nothing leaves your machine.

act 1two identical students race to paint a photo

Both start knowing nothing and learn by practicing a batch of pixels at a time. One picks pixels at random. The other keeps a ledger of its mistakes — in a ClickHouse table running inside this tab — and asks it for the pixels it got most wrong. Same brain, same effort. First to get every patch sharp wins.

Download the race as a GIF

you can interfere: click or drag on the photo (or the ledger) to mark a region "study this now" — the brush is a real priority write, the next batch floods with those pixels, and you'll watch that patch snap into focus.

drop your own photo here to race on it — it never leaves this tab

nothing is simulated: each practice batch is a weighted draw from a real MergeTree table (this loop is prioritized experience replay — what RL and LLM post-training runs do with agent experiences instead of pixels), every error is written back as a priority, and the ledger panel is a live query over that table.
